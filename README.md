# 🤖 J.A.R.V.I.S

A futuristic voice-controlled desktop assistant built with Python.

J.A.R.V.I.S can listen to voice commands, speak responses, open websites, fetch live weather information, manage notes, and provide an interactive GUI experience.

---

## ✨ Features

### 🎤 Voice Assistant
- Speech Recognition
- Text-to-Speech Responses
- Interactive Voice Commands

### 🌐 Web Automation
- Open YouTube
- Open Google
- Open GitHub
- Open ChatGPT
- Open Gmail
- Open LinkedIn
- Open Spotify

### 📅 Utility Features
- Current Time Information
- Live Weather Information
- Google Search from Voice Commands

### 🎭 Fun Features
- Random Jokes
- Motivational Quotes
- Interesting Facts


### 🖥️ GUI Features
- Futuristic Dark Theme Interface
- Live Chat Window
- Status Indicator
- Multithreaded Command Processing
- Startup Greeting

## 🚀 How To Run

1. Clone the repository

```bash
git clone https://github.com/Sayan138387/jarvis-python.git
```

2. Navigate to the project folder

```bash
cd jarvis-python
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run Jarvis

```bash
python gui.py
```
