# Jarvis

A voice-controlled personal assistant built using Python.

## Features
- Speech Recognition
- Text To Speech
- Open YouTube
- Open Google
- Open GitHub
- Open ChatGPT
- Open Gmail
- Open LinkedIn
- Tell Current Time

## Technologies
- Python
- SpeechRecognition
- pyttsx3
- webbrowser

## Features
- Live Weather Information using OpenWeatherMap API
