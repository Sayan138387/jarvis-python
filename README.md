# Jarvis

A voice-controlled personal assistant built using Python.

## Features
- Speech Recognition
- Text To Speech
- Open YouTube
- Open Google
- Open GitHub
- Open ChatGPT
- Open Gmail
- Open LinkedIn
- Tell Current Time
- Live Weather Information using OpenWeatherMap API

## Technologies
- Python
- SpeechRecognition
- pyttsx3
- webbrowser
